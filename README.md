# Space Invaders — Python

A 2D arcade-style Space Invaders game developed using **Python and Tkinter**. Players control a spaceship, shoot incoming enemies, survive increasingly difficult waves, and earn points.

## Features

- Spaceship movement using keyboard controls
- Shooting mechanics and projectile movement
- Multiple waves of moving enemies
- Enemy attacks and collision detection
- Score tracking and lives system
- Increasing difficulty as levels progress
- Game-over screen and restart functionality

## Technologies

- **Python 3** — Game logic and programming
- **Tkinter** — Graphical interface and rendering
- **Random** — Enemy shooting behaviour

The game uses Python's standard library and requires no third-party Python packages.

## How to Run

1. Install Python 3 with Tkinter support.
2. Download or clone this repository.
3. Open a terminal inside the project folder.
4. Run the following command:

`python3 main.py`

The game window will open automatically.

## Controls

| Key | Action |
|---|---|
| Left Arrow / A | Move left |
| Right Arrow / D | Move right |
| Spacebar | Shoot |
| R | Restart after game over |
